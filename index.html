Projeto Destaque

🤖 Optimus Robot

Sistema robótico distribuído com IA local, visão computacional e interface holográfica 3D.

Arquitetura em 3 Módulos — Distribuído em Vision-Core, Brain-Core e Hologram3D com comunicação assíncrona.
NLP Local de Alta Velocidade — Classificação própria de intenções via TF-IDF + similaridade de cosseno (com suporte opcional a OpenAI/LangChain).
Memória Conversacional & Slots — Gestão de sessão inspirada no IBM Watson Assistant, com persistência em Firestore e fallback local.
Visão Computacional em Tempo Real — Reconhecimento facial OpenCV + Dlib via stream DroidCam com eventos no Redis Pub/Sub.
Interface Holográfica 3D & WebSockets — Three.js/WebGL com shaders GLSL, máquina de estados síncrona e sincronia labial via Web Speech API.
Infraestrutura & Testes — Ecossistema containerizado via Docker Compose e suíte de testes de backend em Pytest.
Próximos Passos Planejados — Integração de hardware embarcado com Arduino & NVIDIA Jetson Nano.
Python FastAPI Redis OpenCV Firebase Firestore Three.js WebGL GLSL WebSocket Docker
